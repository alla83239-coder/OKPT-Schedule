# OKPT Schedule

Веб-приложение для подготовки, проверки и автоматизированного составления расписания БПОУ «Омский колледж профессиональных технологий».

## Статус

Начальная архитектура и интерфейсный прототип. Реальные данные из документов пока не импортированы: сначала требуется структурированная проверка извлечения и сопоставления.

## Принципы данных

- Перечень учебных групп формируется **только по файлу «расписание 13 недели.pdf»**.
- Учебные планы и графики учебного процесса определяют учебную нагрузку и календарные периоды, но не создают новые группы самостоятельно.
- Не переносить данные других организаций.
- Не хранить персональные данные, исходные ведомости и внутренние документы колледжа в Git-репозитории.
- Не допускать конфликтов преподавателя, группы, подгруппы и аудитории.
- Недельный лимит группы: до 36 академических часов; дневной: до 4 пар (проверяется в академических часах и парах раздельно).
- Рабочее время преподавателя, педагогическая нагрузка и фактические аудиторные занятия — разные показатели.

## Разработка

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

## Структура

- `src/` — интерфейс прототипа.
- `database/` — схема данных.
- `docs/` — требования, источники и архитектурные решения.

## Безопасность

Репозиторий Private. Исходные документы, ФИО сотрудников, персональные данные обучающихся, учётные данные и реальные выгрузки расписания сюда не добавлять.
